Buffer Overflow Box

This program from Page 11.4 has room for 7 letters in name, plus 1 spot for the terminator \0. Right after it in memory sits another array, pin. Type a name, then copy it in safely or unsafely and watch what happens to pin.

char name[8]; char pin[5] = "1234";

Try a short name first, then something longer than 7 letters, like Christopher.
